## The entry

`main.ts` writes a single original one-line roast of my fridge to `/output/entry.txt`:

> My fridge is the only roommate who eats my leftovers, never pays rent, and still hums like it's doing me a favour.

## Run it

```sh
node main.ts
```

The program is fully deterministic — no randomness, no network, no clock reads — so every run writes byte-identical output. It honours `MAKEFUN_OUTPUT_DIR` when set, defaulting to `/output`.
